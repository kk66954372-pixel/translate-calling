# KoJa Talk 완성 계획 · 체크리스트

_마지막 업데이트: 2026-11-15_

**목표:** 한국인과 일본인이 언어교환하는 **단순한 채팅·전화 번역 앱.** (공부 기능은 넣지 않음)
**핵심:** 어떤 폰이든, 설정 없이, 링크 하나로. 서로의 실제 목소리를 들으면서 화면에는 번역 자막이 뜹니다.
(아이폰 15 Pro 이상끼리, 최신 갤럭시끼리는 휴대폰 기본 통역이 있어서, **기종이 다른 사이·오래된 폰·전용 공간**이 우리 자리)

**포지셔닝 (커넥팅 실사용 후기에서 나온 결론):** "거기서 만나고, 여기서 이어가세요"
- 커넥팅 같은 매칭 앱: 만나서 번역 통화가 되지만 7분 제한, 계속하려면 재화 → 아까워서 카톡/인스타로 옮김
- 그런데 카톡·LINE에는 통화 번역이 없음 → 문자만 하다 지루해져서 인연이 끊김
- **KoJa Talk = 이미 만난 상대와 시간 제한 없이 번역 채팅·통화를 이어가는 곳**
- 요금 원칙: 분 단위 재화 대신 **정액**, **한 명만 결제하면 둘 다 무제한** (배우는 쪽이 결제하고 상대는 무료로 초대), 처음엔 무료 체험
처음에는 나와 일본인 친구 둘이 쓰고, 이후 **월 약 1만 원 구독**으로 많은 사람이 쓰는 서비스로 키웁니다.

## 지금 상태 (한눈에)

| 항목 | 상태 |
|---|---|
| 앱 형태 | 홈 화면 앱(PWA). 아이폰은 Safari에서 "홈 화면에 추가" |
| 주소 | https://koja-talk.onrender.com (Render 무료, 싱가포르) |
| 번역 | Claude **Sonnet 5.5** (채팅·통화 자막 모두), 번역 지시문 v3, 지시문 캐싱 |
| 통화 자막 음성인식 | Deepgram Nova-3. 말할 때만 전송 |
| 통화 연결 | WebRTC + **Cloudflare TURN** (연결 확인: relay 주소 6개 받음) |
| 저장소 | **Neon Postgres** (싱가포르). 계정·대화방·기록 유지 |
| 알림 | 새 메시지·전화·부재중 전화 푸시 (아이폰은 홈 화면 앱, iOS 16.4+) |
| 자동 테스트 | 앱 흐름 28개, 로비 4개, 음성 구간 감지, 가짜 Deepgram. 모두 통과 |

**사용자 1명 한 달 원가 (추정, 통화 10시간 사용자):** 번역 약 3,800원 + 음성인식 약 2,900원 = **약 6,700원**
구독료 1만 원에서 부가세와 결제 수수료를 빼면 약 8,800원이 남으므로 그 안에 들어옵니다. 보통 사용자(통화 4시간)는 약 2,700원입니다.

## 개발 체크리스트

### ✅ 1단계 — 휴대폰에서 끊기지 않게
- [x] 카톡·LINE·인스타 앱 안 브라우저 감지 → Chrome/Safari로 이동, 안 되면 안내
- [x] 통화 중 네트워크 변경(와이파이↔LTE) 시 자동 복구, 통화 중 화면 꺼짐 방지
- [x] TURN 지원 (Cloudflare 임시 자격증명, 서버 시작 시 자동 점검)
- [x] 비용 안전장치: 하루 번역 2000회, 하루 음성인식 600분 한도

### ✅ 2단계 — 휴대폰 통화 자막
- [x] 통화 마이크 소리 → 16kHz 변환 → 서버 → Deepgram 실시간 인식
- [x] 실패하거나 키가 없으면 브라우저 음성인식으로 자동 대체, 음소거 중 전송 중지
- [x] 크레딧 부족/한도 초과 안내 문구

### ✅ 2.5단계 — 홈 화면 앱(PWA) + 카톡 같은 구조
- [x] 계속 유지되는 대화방, 대화방 목록, 안 읽은 수, 대화 기록 저장 (방마다 최근 1000개)
- [x] 접속 상태 표시 ("온라인" / "3분 전 접속")
- [x] 푸시 알림, 앱 밖에 있는 친구에게 전화 → 앱을 열면 바로 울림 (45초)
- [x] 홈 화면 설치 안내, 6자리 코드로 계정 이어서 쓰기, 앱 아이콘·배지

### ✅ 3단계 — 번역 품질과 비용
- [x] 번역 모델 비교 4차례 (일상 30 + 감정 20문장)
      → **채팅·자막 모두 Sonnet 5.5 + 지시문 v3**. Haiku는 감정 문장에서 없는 말을 덧붙인 적이 있어 제외 (もう知らない！→ "이제 몰라! 너 진짜 싫어!")
- [x] 지시문 v3: 친구 사이 말투·감정의 세기·신조어·말버릇 유지, 「お前/あなた/당신」 금지, 웃음·울음 표시 변환
- [x] 번역문만 담는 JSON 출력 (모델의 메모가 화면에 섞이지 않게)
- [x] 지시문 캐싱 → 문장당 $0.0023 → **$0.00054 (77% 절감)**, 평균 응답 약 2.2초
- [x] 말할 때만 음성 보내기 → 대화 한 차례 기준 오디오의 약 55%를 보내지 않음, 말이 멈추면 문장 바로 마무리
- [x] 랜덤 매칭 제거

### 4단계 — 여러 사람이 쓰는 유료 서비스로 (이 순서로 진행)
- [x] ① **계정 로그인** — Google + 이메일 인증 코드 (Apple은 정식 앱 때). 여러 기기 로그인, 로그아웃, 로그인 전 대화방 합치기
      사용자 할 일: Google 클라이언트 ID, Brevo API 키 + 보내는 주소 인증 → Render에 등록
- [ ] ② **사람별 사용 한도** (지금 한도는 서버 전체에 하나) + **신고·차단**, 이용 규칙 (앱스토어 심사에서도 요구)
- [ ] ③ **구독 결제** (웹 결제: 토스페이먼츠 등). **한 명 결제로 둘 다 무제한(페어 요금)**, 무료 체험, 해지·환불, 공정 사용 한도(월 20~30시간)
- [ ] ④ 번역 결과 스트리밍 (더 빨리 보이게), 자막 크게 보기
- [ ] 공개 접속자 목록: 남길지 / 없앨지 결정
- [ ] 유료 서버로 이전 (Render Starter, 항상 켜짐), 오류 모니터링
- ~~표현 즐겨찾기, 통화 후 복습 노트~~ → 넣지 않기로 함 (단순한 번역 앱 방향)

### 5단계 — 정식 앱 (유료 사용자가 생기면)
- [ ] 지금 코드를 감싸서 App Store / Google Play 출시 (Capacitor)

- [ ] 스토어 결제, 휴대폰 자체 음성인식으로 비용 절감 검토

### 법·행정 (사용자 결정, Claude는 초안 지원)

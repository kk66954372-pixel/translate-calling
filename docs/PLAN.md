# KoJa Talk 완성 계획 · 체크리스트

목표: **나(한국어)와 일본인 친구가 휴대폰/PC 어디서든 링크 하나로 전화하고, 서로의 실제 목소리를 들으면서 화면에 번역 자막을 보는 것.**

"완성"의 기준
1. 친구가 카톡/LINE으로 받은 링크를 눌러 **휴대폰에서** 바로 들어올 수 있다.
2. 한국 ↔ 일본, 와이파이 ↔ 모바일 데이터 사이에서도 **통화가 끊기지 않고 연결된다.**
3. 말하면 **2초 안팎**으로 상대 화면에 번역 자막이 뜬다 (휴대폰 포함).
4. 잠깐 신호가 끊기거나 화면이 꺼져도 **방이 깨지지 않는다.**
5. 비용이 예상 범위를 넘지 않는다 (한도 설정).

## A안 vs B안 결론

| | A안: 외부 브라우저로 열기 | B안: 서버 음성인식 (Deepgram) |
|---|---|---|
| 해결하는 문제 | 카톡/LINE 안 브라우저에서 마이크가 막히는 문제 | 휴대폰에서 통화 + 음성인식을 동시에 못 하는 문제 |
| 필요성 | **필수** (B안을 해도 통화 자체가 마이크를 쓰므로 필요) | **휴대폰 자막의 진짜 해결책** |
| 비용 | 0원 | Deepgram 가입 시 무료 크레딧(약 $200, 수백 시간 분량) → 이후 1시간 약 $0.5 내외 |
| 장점 | 간단 | ① 통화에 쓰는 마이크 소리를 그대로 서버로 보내므로 마이크 충돌 없음 ② 에코 제거된 소리를 쓰므로 스피커 소리가 내 자막으로 잡히는 문제 감소 |

→ **둘 다 합니다. A안은 지금 바로, B안은 Deepgram 키를 받은 뒤.** 키가 없을 때는 지금처럼 브라우저 음성인식으로 자동 대체됩니다.

## 개발 체크리스트 (Claude가 진행)

### 1단계 — 모바일에서 끊기지 않게 (키 없이 가능)
- [x] 계획서/체크리스트 작성
- [x] **A안** 카톡·LINE·인스타 등 앱 내 브라우저 감지 → 외부 브라우저(Chrome/Safari)로 자동 이동, 안 되면 안내 + 링크 복사 버튼
- [x] 공유 링크에 `openExternalBrowser=1` 포함 (LINE에서 바로 외부 브라우저로 열림)
- [x] **고정 방 링크** — 한 번 만든 링크를 계속 사용. 먼저 들어온 사람이 기다리고, 나중에 들어온 사람과 연결. 서버가 재시작돼도 같은 링크 그대로
- [x] **재접속 유지** — 신호가 잠깐 끊겨도 60초 동안 방 유지, 다시 연결되면 대화 그대로 이어짐. 상대 화면에 "연결 끊김/재연결" 표시
- [x] 통화 중 네트워크가 바뀌면(와이파이↔LTE) 통화 자동 복구 (ICE restart)
- [x] 통화 중 화면 꺼짐 방지 (Wake Lock)
- [x] **TURN 서버 지원** — Cloudflare 키가 있으면 자동으로 임시 TURN 자격증명 발급
- [x] **비용 안전장치** — 하루 번역 횟수 한도 (`DAILY_TRANSLATION_LIMIT`, 기본 2000회 ≈ Opus 기준 최대 약 $10/일)

### 2단계 — 휴대폰 통화 자막 (B안, Deepgram 키 필요)
- [x] 통화 마이크 소리를 16kHz로 변환해 서버로 전송 (AudioWorklet)
- [x] 서버 ↔ Deepgram 실시간 스트리밍 (Nova-3, 각자 모국어로 인식)
- [x] 키가 없거나 실패하면 브라우저 음성인식으로 자동 대체
- [x] 음소거 중에는 소리를 보내지 않음 (비용 절약), 재접속 후 자동 재시작
- [x] 크레딧 부족/하루 한도 안내 문구 (Claude·Deepgram 모두), 하루 음성인식 한도 `DAILY_STT_MINUTES` (기본 600분)
- [ ] 실제 Deepgram으로 한국어·일본어 인식 확인 (배포 후 실기기 테스트)

### 3단계 — 속도와 품질
- [ ] 번역 지연 측정 표시 (개발용) → Opus vs Haiku 비교 후 기본값 결정
- [ ] 번역 결과 스트리밍 (긴 문장도 앞부분부터 바로 표시)
- [ ] 자막 글자 크기 조절, 자막만 크게 보기 모드

### 4단계 — 언어교환 기능 (완성도)
- [ ] 통화 기록 저장/다시 보기 (기기에 저장)
- [ ] 표현 즐겨찾기 ⭐
- [ ] **통화 후 복습 노트** — Claude가 오늘 대화에서 배울 만한 표현 5개를 각자의 언어로 정리
- [ ] 홈 화면에 앱처럼 추가 (PWA: 아이콘, 전체 화면)

### 5단계 — 운영
